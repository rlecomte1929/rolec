# Eval — `classifier/v1.txt` (document classifier)

**Cohort:** C1-04a (AIQ-490) · **Classes:** 10 — the **Cohort-1 subset of the
canonical Document Types catalog** (`1a0265f08c6e4d48b0bc6c2b3aa52750`).
**Model under test:** `gpt-4o-mini` (default) · `gpt-4o` (escalation when confidence < 0.80)

> **Class-count resolution (2026-06-04):** the original prompt implemented 17
> *inferred* codes; the task title guessed 12. Reconciled against the canonical
> catalog, the classifier's true scope is the **10 Cohort-1 codes** below. See
> "Resolution" at the bottom for the full realignment. Cohort-2 documents (tax
> certificate, birth/marriage certificate, criminal record, housing lease) are
> out of scope and must classify as `UNKNOWN`.

The 10 Cohort-1 codes: `PASSPORT_TD3`, `EU_NATIONAL_ID`, `RESIDENCE_PERMIT_EU`,
`EMPLOYMENT_CONTRACT`, `PAYSLIP`, `DIPLOMA_BACHELOR`, `DIPLOMA_MASTER`,
`ANABIN_EVIDENCE`, `ZAB_STATEMENT_OF_COMPARABILITY`, `HEALTH_INSURANCE_PROOF`
(+ `UNKNOWN`).

This eval validates the prompt on 10 fixture documents spanning all 10 codes,
the 3 highest-stakes disambiguation pairs, and the out-of-scope `UNKNOWN` path,
across the Cohort-1 corridor languages (FR / DE / NO / NL / EN / HI).

## Acceptance bar (Notion AIQ-490)

| Check                                                                | Target    |
|----------------------------------------------------------------------|-----------|
| Accuracy on the 10 fixtures with the default model alone             | ≥ 90 %    |
| `code` is always one of the 10 codes or `UNKNOWN` (no variants)      | 100 %     |
| Output is valid JSON (parseable, no fences)                          | 100 %     |
| Out-of-cohort fixture (F10) returns `UNKNOWN`                         | required  |

Deferred to the C1-04 executor (not this prompt's gate):
- ≥ 95 % accuracy on a 60-document held-out fixture (≈ 6 per type × 10 types)
- escalation-to-stronger-model when confidence < 0.80 working end-to-end

## Methodology

For each fixture below:

1. Render the prompt by substituting the fixture's `{{ document_text }}`.
2. Call the default classifier model (e.g. gpt-4o-mini) with the rendered prompt.
3. Parse the JSON output.

Scoring rules:
- **Pass** when `code` equals the fixture's gold label AND the output is valid
  JSON with a `confidence` float and 2-4 `signals`.
- A disambiguation fixture (F2, F6, F7) also fails if the model picks the
  confusable sibling instead of the gold label.
- F10 passes only when `code == "UNKNOWN"` (it must NOT force a best guess onto
  an out-of-cohort document).

## Fixtures

### F1 — PASSPORT_TD3 (FR, clear positive)
Gold: `PASSPORT_TD3`. A French passport page with a two-line TD3 MRZ
(`P<FRA…`). Expect confidence ≥ 0.95, signal citing the TD3 MRZ.

### F2 — EU_NATIONAL_ID vs RESIDENCE_PERMIT_EU (DE, disambiguation)
Gold: `EU_NATIONAL_ID`. A German `PERSONALAUSWEIS` with
`Staatsangehörigkeit DEUTSCH` (citizen, TD1 MRZ `IDD…`). Must NOT be classified
as `RESIDENCE_PERMIT_EU` — the citizen-vs-non-citizen distinction is the test.

### F3 — RESIDENCE_PERMIT_EU (DE Aufenthaltstitel)
Gold: `RESIDENCE_PERMIT_EU`. A German `AUFENTHALTSTITEL` with
`Anmerkungen: Blaue Karte EU` issued to an Indian national. Signal must cite the
residence-purpose text + non-citizen holder.

### F4 — EMPLOYMENT_CONTRACT (DE Arbeitsvertrag)
Gold: `EMPLOYMENT_CONTRACT`. A German `ARBEITSVERTRAG` with §§ clauses
(Vertragsbeginn, Vergütung, Probezeit). Must NOT be `PAYSLIP`.

### F5 — PAYSLIP (FR bulletin de paie)
Gold: `PAYSLIP`. A French `BULLETIN DE PAIE` for one month with
`Salaire brut` / `Net à payer`. Must NOT be `EMPLOYMENT_CONTRACT`.

### F6 — DIPLOMA_BACHELOR vs DIPLOMA_MASTER (level disambiguation)
Gold: `DIPLOMA_MASTER`. An Indian university certificate awarding a
`MASTER OF SCIENCE` (ISCED 7). Must NOT be `DIPLOMA_BACHELOR` — the level is the
test. (Pair with a bachelor variant as F6b in the held-out set.)

### F7 — ANABIN_EVIDENCE vs ZAB (recognition-artefact disambiguation)
Gold: `ANABIN_EVIDENCE`. An `anabin.kmk.org` printout with `Status H+`. Must NOT
be `ZAB_STATEMENT_OF_COMPARABILITY` (the ZAB is a formal Zeugnisbewertung
letter, not a database printout) and must NOT be a `DIPLOMA_*` (it is evidence
*about* a degree, not the degree).

### F8 — ZAB_STATEMENT_OF_COMPARABILITY (DE)
Gold: `ZAB_STATEMENT_OF_COMPARABILITY`. A
`ZEUGNISBEWERTUNG FÜR AUSLÄNDISCHE HOCHSCHULQUALIFIKATIONEN` from the ZAB with a
`Deutsche Entsprechung` mapping.

### F9 — HEALTH_INSURANCE_PROOF (DE gesetzlich)
Gold: `HEALTH_INSURANCE_PROOF`. A `Techniker Krankenkasse` statutory
`MITGLIEDSBESCHEINIGUNG` with insurer, policy number, coverage start.

### F10 — UNKNOWN (out-of-cohort: Cohort-2 document)
Gold: `UNKNOWN`. A German `LOHNSTEUERBESCHEINIGUNG` (annual tax certificate —
`TAX_CERT`, Cohort 2). The model must return `UNKNOWN` with confidence 0.2-0.4
and a signal noting it is out of the Cohort-1 scope — NOT a forced best guess.

## What to do when a check fails

- **Identity confusion (F2)** — sharpen the PASSPORT_TD3 / EU_NATIONAL_ID /
  RESIDENCE_PERMIT_EU disambiguation tip; the citizen-vs-non-citizen and
  TD3-booklet-vs-TD1-card cues are the deciding features.
- **Degree-level confusion (F6)** — add explicit ISCED-6 vs ISCED-7 / Bachelor
  vs Master exemplars.
- **Recognition-artefact confusion (F7/F8)** — reinforce that ANABIN is a
  database printout (H+/H/H-, anabin.kmk.org), ZAB is a Zeugnisbewertung letter,
  and neither is the DIPLOMA itself.
- **F10 forced a guess instead of UNKNOWN** — strengthen Hard Rule 3 and the
  out-of-cohort framing; add more Cohort-2 negative exemplars.

## Resolution — realignment to the canonical catalog (2026-06-04)

The original v1 prompt was authored without consulting the Document Types
catalog and diverged from it in names, granularity, and scope. Reconciled
against the catalog's **Cohort 1** rows:

- **Kept (5):** `PASSPORT_TD3`, `EU_NATIONAL_ID`, `EMPLOYMENT_CONTRACT`,
  `PAYSLIP`, `HEALTH_INSURANCE_PROOF`.
- **Renamed (1):** `EU_RESIDENCE_PERMIT` → `RESIDENCE_PERMIT_EU`.
- **Split (1→2):** `DIPLOMA` → `DIPLOMA_BACHELOR` + `DIPLOMA_MASTER`.
- **Added (2, catalog-only):** `ANABIN_EVIDENCE`,
  `ZAB_STATEMENT_OF_COMPARABILITY` (German degree-equivalence artefacts).
- **Dropped (10, not Cohort-1 / not in catalog):** `VISA_STAMP`, `OFFER_LETTER`,
  `TAX_RECORD`, `ACADEMIC_TRANSCRIPT`, `BIRTH_CERTIFICATE`,
  `MARRIAGE_CERTIFICATE`, `POLICE_CLEARANCE`, `PROOF_OF_ADDRESS`,
  `BANK_STATEMENT`, `CV_RESUME`. Several map to **Cohort 2** catalog codes
  (`TAX_CERT`, `BIRTH_CERT`, `MARRIAGE_CERT`, `CRIMINAL_RECORD`, `HOUSING_LEASE`)
  and should be added when Cohort 2 comes into scope.

Catalog reference: `Document Types` DB
`1a0265f08c6e4d48b0bc6c2b3aa52750`. Code names match the catalog's `Code`
titles exactly so downstream extraction agents (PASSPORT, PAYSLIP,
EMPLOYMENT_CONTRACT, …) key on the same identifiers.
