# ie-driving-licence-2026-09-10 — IE driving-licence exchange guide (A-P5)

**City:** Dublin (IE) · **Category:** transport · ImportBundle JSON.

## What this is
A licence-exchange guide with 5 resources covering both paths:
- **ES->IE (EU direct exchange):** Spain is EU/EEA, so a valid Spanish licence exchanges directly for an Irish one — no test; within 10 years of expiry; apply at NDLS; documents incl. proof of residence for non-EU-born applicants; EUR 65 fee.
- **VE->IE (recognised-state check / test):** Venezuela is **NOT** on Ireland's published recognised-states list and is not EU/EEA, so a Venezuelan licence **cannot be exchanged** — the holder drives as a visitor up to 12 months with an IDP, then must sit the Driver Theory Test + learner permit + EDT + driving test.

## Venezuela status — stated honestly
Venezuela's exclusion is a documented **absence** from the official recognised-states list on citizensinformation.ie, combined with the official NDLS/RSA fallback rule that a licence from a no-agreement country cannot be exchanged. No official page affirmatively names Venezuela in either direction; nothing was invented. If maximum certainty is needed, additionally verify the RSA/NDLS "recognised states" list pages.
