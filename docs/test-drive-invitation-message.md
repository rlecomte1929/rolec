# Test-Drive — outreach kit

**Purpose:** the message Romain sends to invite contacts to test ReloPass. Three formats — a **full** version (summarizes the test, steps, videos, stop point, and survey), a **short teaser** (just gets the click, detail lives on the page), and a **WhatsApp cohort broadcast** (one-to-many, opens with the "you've heard me talk about this" hook). Pick per channel/contact.

---

## Recommendation on the time estimate

**State it. ~20 minutes.** Omitting a number reads as evasive and *lowers* completion — people assume the worst. A concrete, small number caps the perceived cost. It's the single most reassuring line in the message.

# FULL version (carries the summary)

Use this when you want the email itself to explain the test — good for contacts who won't click through cold.

## Full — Version A · friends / warm network (`internal`)

> **Subject:** 20 minutes to help me stress-test ReloPass?
>
> Hi {First name},
>
> I'm building ReloPass — infrastructure for running corporate relocations — and before I put it in front of buyers, I want people I trust to try to break it.
>
> Everything's on one page: **{https://relopass.com/test-drive}**
>
> **What it is:** you'll run one relocation from both sides — the HR manager who sets up the case, and the employee who goes through it — all on sample data, nothing real. The goal is simple: find where it's confusing, slow, or breaks.
>
> **How it goes (about 20 minutes):**
> 1. Open the page and hit start — it creates your two logins, HR and Employee.
> 2. There are short reference clips on the page if you'd like to see the basics first.
> 3. Run the HR side, then switch and run the employee side.
> 4. You're done once the roadmap is in place and you've picked a vendor with an estimated cost — then hit "I've completed my test."
>
> **The last step matters most:** a short survey at the end. That's where your honest read really helps me — please don't skip it. There's also a feedback button throughout for anything good or bad, as you go.
>
> Thank you for giving this your time — it genuinely moves the needle for me.
>
> Romain

## Notes for use
- **One link for everyone: `relopass.com/test-drive`** (plain, no `?corridor=`). The system auto-assigns each tester a corridor (Tier-A weighted) — testers don't choose one and don't need to know about it, so no corridor is mentioned in any message. Requires TD-13 live before sending to the cohort.
- Swap `{First name}` and confirm the `/test-drive` URL before sending.
- Keep it plain-text and personal — no logo header, no marketing chrome. It should read like a note from Romain, not a campaign blast.
- Tag each invite with the segment (`internal` / `prospect`) so the results slice matches spec §3 — and so the funnel counts invites-sent (spec §6.1).
- Version B seeds the referral ask ("someone who should see it") so the survey's intro question doesn't feel abrupt.
- The full version front-loads the steps; if a contact is likely to just click, the short teaser converts better. When unsure, send the full one.
